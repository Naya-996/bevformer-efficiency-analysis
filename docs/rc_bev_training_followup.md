# RC-BEV 后续训练计划

本轮包含 5 种配置、12 个训练任务。实验要分别衡量缩小 BEV 网格的影响、连续 BEV query 的贡献，以及一个 checkpoint 在多个网格尺寸下的精度和耗时。数字 150 和 200 表示 BEV 网格的边长。后缀 `s0`、`s1`、`s2` 分别代表随机种子 0、1、2。

## 实验矩阵

| 配置 | 种子 | 训练数 | 用途 |
| --- | --- | ---: | --- |
| `base200` | 0、1、2 | 3 | 原版 BEVFormer，固定 200×200。建立高分辨率基线，观察基线的种子波动。 |
| `discrete150` | 0、1、2 | 3 | 原版的离散 BEV query，固定 150×150。与同种子的 `base200` 对照，衡量缩小网格的影响。 |
| `rc_fixed150` | 0、1、2 | 3 | 连续 BEV query，固定 150×150。与同种子的 `discrete150` 对照，在相同网格尺寸下衡量 RC 配置的贡献。 |
| `rc_fixed200` | 0 | 1 | 连续 BEV query，固定 200×200。与 `base200_s0` 对照，检查高分辨率下的变化。 |
| `rc_multires` | 1、2 | 2 | 多分辨率训练。每个种子训练一套权重，再分别以 100、125、150、175、200 五档网格评估。 |

200×200 有 40,000 个 BEV 位置，150×150 有 22,500 个，位置数减少 43.75%。端到端延迟和峰值显存以实测为准。

## 如何比较

- **同分辨率看方法收益。** 对 `rc_fixed150` 和 `discrete150` 按种子配对，报告每对的 mAP、NDS 差值及总体均值和标准差。固定验证集、评估设置和训练预算。
- **同一权重看分辨率取舍。** 对每个 `rc_multires` checkpoint 分别评估五档，报告 mAP、NDS、延迟和峰值显存。与同档的固定分辨率模型对照时，记录训练策略的差异。
- **单独解释 200 档的单种子实验。** `rc_fixed200_s0` 与 `base200_s0` 提供一个高分辨率配对。跨种子的 RC 收益主要看三对 150 档实验。
- **记录 GPU 数和全局 batch。** 原计划双卡、每卡 1 样本，全局 batch 为 2。单卡 `base200_s1` 保留每卡 1 样本，全局 batch 为 1。同样的 epoch 数对应不同的优化器更新次数，汇总时应将这一运行条件单独标注。
